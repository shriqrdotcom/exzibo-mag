==================================================

- PUT
- PATCH
- DELETE

Do NOT require CSRF for:

- public unauthenticated booking creation unless current policy already requires it;
- server-to-server webhook/publish endpoints with signed secrets;
- OPTIONS preflight.

Failure response:

- status 403
- safe Prompt 25A error envelope
- includes requestId
- no secret or allowlist leakage

==================================================
CONFIRMED DEFECT
==================================================

Analytics currently use JavaScript Date or server timezone boundaries.

This can cause:

1. Revenue to be assigned to the wrong business day.
2. Customer activity to be assigned to the wrong day.
3. Month/week/day buckets to shift around midnight.
4. DST transitions to produce incorrect bucket boundaries.
5. Different deployment servers to produce different analytics.

==================================================
OBJECTIVE
==================================================
